# CITATIONS

If you use, fork, or build upon Surf FED in academic work, a blog post, or a
derivative project, please cite it and link back to the repository. A
suggested citation and BibTeX entry are below.

## Suggested citation

> Surf FED Team. *Surf FED — an Electron web browser with custom extension
> support.* https://github.com/Surf-FED/Surf-FED-Internet-Browser-With-Extensions

## BibTeX

```bibtex
@misc{surffed,
  author       = {{Surf FED Team}},
  title        = {Surf FED --- an Electron web browser with custom extension support},
  year         = {2024},
  howpublished = {\url{https://github.com/Surf-FED/Surf-FED-Internet-Browser-With-Extensions}},
  note         = {Accessed: YYYY-MM-DD}
}
```

## Referenced works

Surf FED builds on the following projects, which should also be cited when
relevant to your work:

- **Electron** — <https://www.electronjs.org/>
- **electron-builder** — <https://www.electron.build/>
- **Chromium** — <https://www.chromium.org/>
- **FED-GRAM** — original Python/Streamlit application, source and license
  preserved under `extensions/builtin/fed-gram/original/`. See that folder's
  `README.md` and `LICENSE` for the original project's citation and terms.
