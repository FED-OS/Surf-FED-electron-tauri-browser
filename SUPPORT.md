# Support

## Where to get help

| If you… | Then… |
|---------|-------|
| Have a "how do I…?" question | Open a **Discussion** (Q&A category). See `.github/DISCUSSION_WELCOME_README.md`. |
| Found a bug | Open an issue with the **Bug Report** template (`.github/ISSUE_TEMPLATE/bug_report.md`). |
| Want to suggest a feature | Open an issue with the **Feature Request** template, or discuss it first in Discussions. |
| Need help with an extension | Use the **Extensions** Discussion category. Also see `EXTENSIONS.md`. |
| Found a security vulnerability | **Do not open a public issue.** Use GitHub Security Advisories or email `security@fedpromptly.com`. See `SECURITY.md`. |

## Before asking

To get a fast, useful answer:

1. **Search existing Discussions and issues** — your question may already be
   answered.
2. **Include your environment** — Surf FED version (in `package.json` or
   Help → About), OS, and whether you ran from source or a downloaded build.
3. **Reproduce it** — exact steps, and any console output (open Developer
   Tools from the View menu, or run `npm start` in a terminal).
4. **For extensions** — note whether the problem happens with all extensions
   disabled.

## Response expectations

This is a small community project. Maintainers and contributors answer when
they can; there is no paid support SLA. Being specific and kind (see
`CODE_OF_CONDUCT.md`) gets you help faster.
